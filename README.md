# A4 绘画标尺工作台

面向传统手绘、建筑速写、彩铅和水彩的二维构图工具。将参考照片放入 ISO A4 画纸，以真实的毫米坐标定位、测量和记录建筑轮廓。默认简体中文，无需账户、数据库和付费 API，参考图片在本地浏览器中处理。

## 本地运行

建议使用 Node.js 22 或更新版本及 Chrome / Edge 最新稳定版。

```bash
npm ci
npm run dev
```

打开终端给出的本地网址。开发服务默认监听所有网卡，如只需本机访问，可使用 `npx vite --host 127.0.0.1`。

```bash
npm test       # 几何精度、项目校验及 SVG 导出测试
npm run build # TypeScript 检查、生产打包及 PWA 生成
npm run preview # 预览生产版本；离线能力在生产版本验证
npm run test:browser # 另开终端启动 dev 后，执行 23 项浏览器断言
npm run test:gestures # dev 端口 5173：9 项图片与真实触摸事件断言
npm run test:offline # preview 端口 4173：5 项离线断言
```

浏览器测试使用 `playwright-core`：Linux 自动使用 `/usr/bin/chromium`，其他平台默认调用已安装的 Google Chrome。可设置 `CHROMIUM_PATH` 指定浏览器路径，或设置 `TEST_URL` 测试其他本地服务地址。测试会使用独立、临时浏览器上下文，输出到 `work/`。

`dist/` 可部署到任意支持 HTTPS 的静态站点服务。直接双击 HTML 文件无法运行模块及 Service Worker。离线功能需要 HTTPS 或 localhost。

## 使用方法

1. 导入 JPG、PNG、WEBP 等图片，或拖入工作区；“试用建筑构图示例”可快速体验。
2. 用选择工具拖动图片、拖动四角等比缩放；在属性中输入 X/Y、宽高、缩放和旋转。适应、填满、居中、翻转、透明度、锁定均可使用。
3. 工作区滚轮缩放只改变显示，不改变毫米坐标。图片缩放会改变图片占据的画纸尺寸。
4. 使用坐标点、测距、直线、矩形及水平/垂直辅助线。两次点击分别设置起点和终点。选中对象后，在“标记与辅助线”输入精确坐标和样式，也可拖动端点或整体移动。坐标文本可选择和复制。
5. 每次修改后约 650 ms 自动保存到 IndexedDB。顶部“保存项目”下载 `.a4r` 文件，这是包含 JSON 和完整内嵌图片的 ZIP。通过“打开项目”或拖入文件恢复。
6. 导出 PDF、150/300 DPI PNG 或坐标 CSV。PDF 严格使用 210 × 297 mm / 297 × 210 mm 页面，无页边距。打印时选择“实际尺寸 / 100%”，关闭“适应页面”。导出遵循图层显示状态，可额外选择内容、标签、内侧标尺及边框。
7. 设置中可使用 100 mm 或 50 mm 线段校准屏幕显示。校准只保存到本机，不影响项目坐标和 PDF 尺寸。

## 已实现

- 标准 A4 横竖方向、左上角原点、X 向右/Y 向下；SVG 毫米空间独立于浏览器像素与设备像素比。
- 自适应 1/5/10 mm 标尺、1/5/10/20 mm 及自定义网格（1–100 mm），主次网格、颜色、透明度、吸附。
- 图片本地解码、裁切显示、无损几何变换，移动、等比四角缩放、数字缩放、旋转、翻转、透明度、适应/填满/重置/居中和锁定。
- 命名坐标标记、精确添加/编辑、复制、拖动和删除；测距的 ΔX、ΔY、长度和角度；线段、矩形、水平和垂直辅助线。
- 对象的颜色、线宽、虚线、显隐和锁定；图片/网格/辅助线/坐标点分层显隐。
- 最多 70 次撤销/重做；整次拖动作为一次撤销；方向切换保留毫米数据。
- 光标中心滚轮缩放、空格拖动、工具快捷键、触屏对象拖动、双指缩放与平移。
- IndexedDB 自动保存、可移植项目 ZIP、300 DPI PNG、物理尺寸准确的 A4 PDF、UTF-8 BOM CSV。
- PWA 应用清单、图标和核心静态资源预缓存；首次完整加载并激活 Service Worker 后可离线运行。
- 数值范围校验、项目格式验证、上传/解码/存储/导出错误提示、移动端可折叠属性面板。

## 精度与限制

几何始终使用 JavaScript 双精度毫米数值，界面通常显示一位小数；坐标 CSV 保留四位。SVG 根据设备分辨率渲染，拖动坐标通过画纸变换反算。屏幕显示的“100%”仅为 CSS 像素基准，物理显示需自行校准。

- PDF 内嵌 150/300 DPI 栅格图；页面物理尺寸精确，辅助线不作为独立矢量对象保存。PDF 标签仍是图像的一部分。
- 为控制内存，单张上传限制 40 MB、解码图像不超过 1 亿像素。较大图像自动下采样到最长边 6000 像素且最多约 2000 万像素；保留原始长宽比及尺寸信息。后续缩放不会反复重采样。项目中保存处理后的图片；需要原始像素时请另存原文件。
- 可移植项目上限 65 MB，最多 10000 个对象。高密度对象和 300 DPI 导出可能需要短暂等待。
- 本地自动保存只保留当前画作，不提供多个项目目录；请用 `.a4r` 文件管理多个画作。历史撤销栈与工作区倍率不属于项目数据。
- 浏览器清理站点数据、隐私模式限制、存储空间不足可能导致本地保存不可用，界面会提示。请保留项目文件备份。
- 当前不提供自由笔刷、OCR、透视变形、多图拼贴和云同步，这些不属于毫米辅助构图核心范围。
- PWA 安装及离线存储由浏览器提供；首次加载尚未完成缓存时不可离线使用。
- 验证环境为 Linux Chromium，桌面高 DPI 及移动视口已测试；未在实体 Windows、手机或打印机上验证。
